# JavBoss 个人资源库（Mac Apple 芯片版）

## 启动

双击 `javboss.command`。浏览器会自动打开本机的资料库页面。

## 资料保存位置

所有作品、演员、标签、评分、备注和封面都存放在同一文件夹内的 `data` 文件夹中。

## 备份

先退出 JavBoss，再完整复制整个 `data` 文件夹到移动硬盘、iCloud Drive 或其他安全位置。不要只复制其中的 `javboss.db` 文件。

## 浏览器助手回填

当作品的直接刮削失败或资料不完整时，可使用随程序附带的 `browser-extension` 文件夹：

1. 在 Chrome 中打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本程序文件夹里的 `browser-extension`。
3. 刷新 JavBoss。在“作品”页打开某部自定义作品的“手动刮削”，点击“打开 JavBus / JavLibrary / JavDB / AVSOX”。
4. 在打开的作品详情页点右下角“回填到 JavBoss”，检查资料后再点击保存。

更新程序后，请在 Chrome 的扩展页面点击 JavBoss 助手的“重新加载”按钮。

## 批量整理

作品封面左上角可勾选多部作品，也可点击页面上方“全选本页”。选好后点击“批量编辑”，即可一次添加多个自定义标签，或将作品加入一个或多个收藏夹。批量添加只会追加信息，不会清除作品原有标签或收藏。

## 升级

替换程序文件前，先复制 `data` 文件夹作为备份；升级后保留或放回原来的 `data` 文件夹即可。
